# spotifytom4a
Take a Spotify playlist and convert the songs to M4As

### Steps:
1. Install ytdlp, ffmpeg, atomicparsley, deno (note: the age verification is set up with firefox)
2. https://exportify.net/ & download the .csv you want
3. download python script and run `python spotifytom4a.py --csv "playlist.csv" --output "OUTPUT_DIR"`
4. Run script
